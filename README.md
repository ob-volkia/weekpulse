# Weekpulse

Недельный планер для Obsidian. Задачи раскладываются по дням, перетаскиваются мышью или пальцем, невыполненное само переезжает на сегодня. Есть профили «Работа / Личное», привычки, таймер фокуса, статистика и итоги недели. Работает на компьютере и на iPhone, данные хранятся в обычных Markdown-файлах.

Интерфейс на русском.

## Установка

Порядок важен: **сначала хранилище в iCloud, потом плагин**. Если создать хранилище «где-нибудь» на компьютере, а синхронизацию захотеть потом, придётся всё переносить.

### Шаг 1. Создай хранилище в iCloud (на iPhone)

Хранилище создаётся именно на iPhone: так Obsidian сам кладёт его в нужную папку iCloud, и оно появляется на всех устройствах.

1. Установи Obsidian из App Store и открой его.
2. «Создать новое хранилище» → придумай название (например «Планер») → включи **«Хранить в iCloud»** → «Создать».
3. **Настройки → Сторонние плагины → Включить сторонние плагины.**

### Шаг 2. Открой это же хранилище на компьютере

1. Установи [Obsidian](https://obsidian.md) на Mac.
2. Подожди минуту, пока iCloud синхронизирует папку.
3. В Obsidian: «Открыть папку как хранилище» → **iCloud Drive → Obsidian →** твоё хранилище.
4. Если Obsidian спросит про доверие плагинам этого хранилища, нажми «Доверять» и включи сторонние плагины: **Настройки → Сторонние плагины → Включить**.

### Шаг 3. Поставь плагин (на компьютере)

1. В Finder открой папку хранилища: **iCloud Drive → Obsidian →** твоё хранилище.
2. Покажи скрытые папки сочетанием `Cmd + Shift + .` и зайди в `.obsidian/plugins/` (если папки `plugins` нет, создай её).
3. Скопируй туда папку `weekpulse` из архива. Внутри неё должны лежать три файла: `main.js`, `manifest.json`, `styles.css`.
4. В Obsidian: **Настройки → Сторонние плагины**, нажми кнопку обновления списка и включи **Weekpulse**.

Слева на панели появятся три значка: календарь (неделя), таймер (фокус) и огонёк (привычки и статистика).

### Шаг 4. Включи плагин на iPhone

Файлы плагина доедут на телефон через iCloud сами.

1. Полностью перезапусти Obsidian на iPhone (смахни его из списка приложений и открой снова).
2. **Настройки → Сторонние плагины** → включи **Weekpulse**.

Если плагина нет в списке, подожди пару минут, пока iCloud догрузит файлы, и перезапусти Obsidian ещё раз.

> Если тебе прислали файл `data.json`, его класть не нужно: это чужие настройки.

### Если iPhone нет

Создай хранилище прямо на компьютере. Для синхронизации с другими устройствами потом подойдёт Obsidian Sync или Syncthing. Плагин ставится так же, как в шаге 3, только папка хранилища будет там, где ты её создал.

### Windows

Obsidian на Windows не видит папку iCloud так же удобно, как Mac, поэтому для пары «Windows + iPhone» надёжнее Obsidian Sync. Плагин ставится так же: папка `weekpulse` в `.obsidian/plugins/` хранилища (скрытые папки включаются в Проводнике: «Вид → Показать → Скрытые элементы»).

## Первый запуск

При первом включении плагин сам создаёт папку `Planner/` с файлами задач, привычек и шаблонов. Ничего настраивать не обязательно.

Что стоит сделать в **Настройки → Weekpulse**:

- **Профили.** По умолчанию есть «Работа» и «Личное». Можно переименовать, поменять цвета, добавить свои.
- **Ёмкость дня.** Сколько часов работы в день ты реально планируешь. От этого зависит полоска загрузки дня.
- **Автоперенос невыполненного.** Включён по умолчанию: вчерашние незакрытые задачи утром оказываются на сегодня.
- **Календари.** Можно подключить Google или Apple Календарь, чтобы видеть встречи рядом с задачами (см. [Календари](#календари)).

## Экран недели

### Шапка (компьютер)

- **Слева:** стрелки «назад / вперёд», кнопка «Сегодня» и даты на экране.
- **По центру:** переключатель вида.
- **Справа:** профиль, цели недели, фильтр, поиск, планирование, фокус, привычки, проекты, меню «⋯» и кнопка **«+ Задача»**.

### Виды

| Вид | Что показывает |
|---|---|
| **3 дня** | Бэклог и три широкие колонки: вчера, сегодня, завтра. Стрелки листают по 3 дня. Удобно, когда в задачах много текста. |
| **Неделя** | Бэклог и 7 колонок с понедельника по воскресенье. Основной вид. |
| **Месяц** | Календарная сетка, задачи можно перетаскивать между любыми днями месяца. Клик по числу открывает неделю. |
| **Шкала** | Почасовая сетка. Перетащи задачу на нужный час, время выставится с шагом 15 минут. Задачи без времени лежат полосой сверху. |

Выбранный вид запоминается на каждом устройстве отдельно.

### Колонка дня

- В шапке колонки: день недели, число, «Сегодня / Завтра / Вчера», счётчик выполненного.
- **Полоска загрузки** показывает, сколько часов запланировано относительно ёмкости дня. Если план больше, день подсвечивается красным.
- Клик по числу открывает **заметку дня**.
- `⋯` в шапке колонки: шаблоны дня, фокус на этом дне и другие действия с днём.
- Внизу колонки поле «Добавить…» для быстрой задачи прямо в этот день.

**Бэклог** — задачи без даты. Туда складывается всё «когда-нибудь».

### Карточка задачи

На карточке видно: название, время и длительность, теги, приоритет (цветная полоска), дедлайн, прогресс подзадач, потраченное в фокусе время, проект и цвет профиля.

Значок «↪ N» показывает, сколько раз задачу переносили. После 5 переносов плагин предложит разбить её, отправить в бэклог или удалить.

## Как добавлять задачи

Три способа:

- кнопка **«+ Задача»** в шапке (или клавиша `n`);
- поле «Добавить…» внизу колонки дня;
- `Cmd + Shift + A` из любого места Obsidian.

### Быстрый ввод одной строкой

В поле «Добавить…» и в названии новой задачи можно сразу написать всё остальное, плагин разберёт сам:

| Пишешь | Что получится |
|---|---|
| `сегодня`, `завтра`, `послезавтра`, `пт`, `в пятницу`, `15.12` | день |
| `бэклог` | без даты |
| `14:00`, `в 9:30`, `@9` | время |
| `1ч`, `30м`, `1ч30м`, `1.5ч` | длительность |
| `#работа` | тег |
| `!!!` срочно · `!!` высокий · `!` средний · `!-` низкий | приоритет |
| `до пт`, `до 15.12`, `до завтра` | дедлайн |
| `каждый день`, `по будням`, `каждый пн и чт`, `каждую неделю`, `каждый месяц`, `каждые 3 дня` | повтор |
| `[[Название]]` | задача попадает в проект «Название» |

Пример: `Созвон с клиентом пт 15:00 1ч #работа !!`
Результат: задача «Созвон с клиентом» на ближайшую пятницу в 15:00, на час, с тегом и высоким приоритетом.

## Окно задачи

Открывается кликом по карточке. Сверху название, под ним строка **настроек-«чипов»**, ниже **содержимое задачи**.

**Чипы** (нажми, чтобы изменить):
- день;
- профиль;
- время и длительность;
- дедлайн;
- приоритет;
- теги;
- повтор;
- цель недели.

**Содержимое:**
- **Описание** — подробности, ТЗ, мысли.
- **Подзадачи** — чек-лист внутри задачи.
- **Ссылки** — вставь адрес, плагин сам подтянет заголовок страницы.
- **Файлы** — прикрепи документ или картинку. Файлы хранятся в `Planner/Attachments/`.
- **Комментарии** — заметки по ходу работы, с датой.

Внизу: удалить, запустить фокус на задаче, открыть задачу как отдельную заметку, «Отмена» и «Сохранить».

## Действия с задачами

| Действие | Компьютер | iPhone |
|---|---|---|
| Перенести на другой день | перетащи карточку | удерживай карточку и тяни на день в полосе недели |
| Перенести на неделю вперёд/назад | брось карточку на стрелку в шапке (подержи над ней, чтобы перелистнуть) | так же |
| Выполнено | галочка | галочка или свайп влево |
| На завтра | меню карточки | свайп вправо |
| Быстрое меню | правый клик | нет, все действия есть в окне задачи |
| Несколько задач сразу | `Shift`/`Cmd` + клик | `⋯` → «Выбрать задачи» |

**Быстрое меню** карточки: сегодня / завтра / бэклог, выполнено, фокус, приоритет, сбросить счётчик переносов, дублировать, открыть в файле, удалить.

**Повторяющиеся задачи:** отметил выполненной — следующая появится сама.

**Отмена:** после удаления и массовых действий внизу на несколько секунд появляется «Отменить». На компьютере также работает `Cmd + Z`.

## Профили

Профили разделяют задачи, например на «Работа» и «Личное», но всё остаётся в одном планере.

- Переключатель — кнопка с цветной точкой в шапке. Вариант **«Всё»** показывает задачи всех профилей.
- Новая задача получает текущий профиль. В режиме «Всё» — профиль по умолчанию (настраивается).
- Профиль задачи меняется чипом в окне задачи.
- Задачи без профиля считаются задачами профиля по умолчанию.
- Полоска загрузки дня считает **все** профили, чтобы не перегрузить день скрытыми задачами.
- Выбор профиля запоминается на каждом устройстве отдельно: например, на работе «Работа», дома «Всё».

## Цели, фильтры, проекты

**Цели недели.** Кнопка с мишенью: 1–3 главные цели на неделю. Задачу привязывают к цели чипом в окне задачи. Выбор цели в списке показывает только её задачи. Цели попадают в итоги недели.

**Фильтр.** По тегу, приоритету или цели. Удачную комбинацию можно сохранить под именем и включать одним нажатием.

**Поиск** (`Cmd + K`): находит любую задачу, включая старые выполненные из архива. Найденную можно сразу выполнить, перенести или запустить фокус.

**Проекты.** Если в названии задачи есть ссылка `[[Название]]`, задача попадает в проект. На экране «Проекты» у каждого проекта видно прогресс, сколько времени осталось, просроченные задачи, и можно добавить задачу прямо в проект.

## Планирование и разбор бэклога

**Спланировать неделю** (кнопка с волшебной палочкой или `p`). Слева хвосты прошлой недели и бэклог, справа дни с загрузкой. Раскидываешь задачи перетаскиванием. В воскресенье и понедельник плагин сам предложит это сделать (отключается в настройках).

**Разобрать бэклог** (`⋯` → «Разобрать бэклог» или значок в шапке бэклога). Задачи показываются по одной, начиная с самых старых. На каждую одно решение: сегодня, завтра, на этой неделе, на следующей, оставить или удалить. Клавиши `1`–`4`, пробел, `Backspace`.

**Итоги недели.** Команда «Итоги текущей недели» создаёт заметку в `Planner/Reviews/` с цифрами, сделанным, проектами, привычками и вопросами для рефлексии.

## Фокус и помодоро

Экран фокуса (значок таймера или `f`): список задач на сегодня и таймер помодоро (по умолчанию 25 минут работы и 5 отдыха, меняется в настройках).

- Запусти фокус на конкретной задаче, и потраченное время запишется в неё.
- На карточке время показывается рядом с плановой длительностью: видно план и факт.
- Пробел — старт / пауза.
- На компьютере таймер виден в строке состояния внизу.

**Напоминания.** За 10 минут до задачи со временем приходит уведомление (срок меняется в настройках). На iPhone уведомления приходят, только пока Obsidian открыт.

## Привычки и статистика

Экран «Привычки и статистика» (значок огонька).

**Привычки:**
- добавь привычку и выбери дни (или каждый день);
- отмечай выполнение в сетке недели, серия дней считается сама.

**Статистика недели:** выполнено по дням, по тегам, по проектам, точность оценок времени (план против факта), задачи, которые чаще всего откладываются.

**Тренды** за 4, 8 или 12 недель: процент выполнения по неделям, самые продуктивные дни недели, активность.

## Шаблоны, заметки дня, календари

### Шаблоны

`⋯` → «Шаблоны…»: применить шаблон к неделе или сохранить текущую неделю как шаблон. Через `⋯` в шапке дня — то же для одного дня. Шаблоны хранятся в `Planner/Templates.md`, их можно править вручную.

### Заметка дня

Клик по числу в шапке колонки создаёт заметку `Daily/ГГГГ-ММ-ДД.md` с живым списком задач и привычек дня: их можно отмечать прямо в заметке.

Такой блок можно вставить в любую заметку:

````
```planner-day
2026-11-10
```
````

### Задачи из других заметок

Любая строка вида `- [ ] Сделать что-то 📅 2026-11-10` в любой заметке хранилища появится в неделе (с пунктирной рамкой и названием заметки внизу). Отметка и перенос меняют строку прямо в исходной заметке. Отключается в настройках.

### Календари

Встречи из календаря видны в колонках дней и на шкале и учитываются в загрузке дня. Редактировать их из планера нельзя.

Подключение: **Настройки → Weekpulse → Ссылки на календари (ICS)**, по одной ссылке в строке.

- **Google Calendar:** на компьютере calendar.google.com → настройки нужного календаря → «Интеграция календаря» → «Секретный адрес в формате iCal».
- **Apple Календарь:** в приложении «Календарь» на iPhone → значок (i) у календаря → «Публичный календарь» → «Поделиться ссылкой». Ссылка начинается с `webcal://`, так и вставляй.

Календари обновляются раз в 30 минут и по команде «Обновить календари».

## iPhone

- **Вид:** сверху полоса дней недели, под ней один выбранный день. Нажми на день в полосе, чтобы открыть его.
- **Перенос:** удерживай карточку и тяни на нужный день в полосе.
- **Свайпы:** влево — выполнено, вправо — на завтра.
- **Кнопка «+» в нижней панели Obsidian:** включается в **Настройки → Weekpulse → iPhone**. Это неофициальная возможность: после обновления Obsidian кнопка может пропасть, тогда просто выключи её.
- **Нижняя панель Obsidian** настраивается в **Настройки → Панель инструментов для мобильных**: можно убрать лишние кнопки и добавить команды плагина, например «Открыть неделю» или «Новая задача».
- Вид «3 дня» на телефоне не нужен (там и так один день), поэтому он работает как «Неделя».

## Синхронизация и сохранность данных

Плагин рассчитан на синхронизацию через iCloud (подойдут и Obsidian Sync, Syncthing и другие).

- **Слияние правок.** Если задачи поменяли на двух устройствах почти одновременно, плагин аккуратно сольёт обе версии, а не затрёт одну другой.
- **Копии-конфликты iCloud** вида `Tasks 2.md`: плагин покажет уведомление и предложит слить копию в основной файл.
- **Резервные копии** задач, привычек и целей делаются раз в день в `Planner/Backups/` и хранятся 30 дней. Вернуть: `Cmd + P` → «Восстановить из резервной копии…».
- **Журнал изменений** (`⋯` → «Журнал изменений»): что, когда и с какого устройства менялось. Удалённую задачу можно вернуть оттуда.

> **Важно для iPhone + iCloud:** никогда не нажимай «Удалить хранилище» на iPhone. Это удаляет папку из iCloud сразу на всех устройствах. Если нужно переподключить хранилище, просто закрой его.

Если синхронизация «зависла», первым делом проверь, не закончилось ли место в iCloud.

## Горячие клавиши

Работают на экране недели (компьютер).

| Клавиша | Действие |
|---|---|
| `n` | новая задача |
| `t` | сегодня |
| `[` / `]` | назад / вперёд |
| `3` / `w` / `m` / `l` | вид: 3 дня / неделя / месяц / шкала |
| `p` | спланировать неделю |
| `f` | фокус |
| `d` | показать / скрыть выполненные |
| `Cmd + K` | найти задачу |
| `Cmd + Z` | отменить последнее действие |
| стрелки, `j` / `k` | выбрать карточку |
| `x` или пробел | выполнено |
| `Enter` или `e` | открыть задачу |
| `1`–`7` | перенести выбранную задачу на день недели |
| `0` | в бэклог |
| `Delete` | удалить |
| `Esc` | снять выбор |

В любом месте Obsidian: `Cmd + Shift + A` — новая задача, `Cmd + Shift + K` — поиск задачи.

Все команды плагина есть в палитре команд (`Cmd + P`, начни печатать «Weekpulse»). Там же им можно назначить свои сочетания: **Настройки → Горячие клавиши**.

На Windows вместо `Cmd` — `Ctrl`.

## Где хранятся данные

Всё лежит в обычных файлах внутри хранилища, их можно открыть и поправить руками:

| Путь | Что там |
|---|---|
| `Planner/Tasks.md` | все текущие задачи, одна строка — одна задача |
| `Planner/Habits.md` | список привычек и журнал отметок |
| `Planner/Goals.md` | цели по неделям |
| `Planner/Templates.md` | шаблоны дня и недели |
| `Planner/Tasks/` | описания, ссылки и комментарии задач |
| `Planner/Attachments/` | прикреплённые файлы |
| `Planner/Archive/` | старые выполненные задачи (переезжают туда через 30 дней) |
| `Planner/Reviews/` | итоги недель |
| `Planner/Backups/` | ежедневные резервные копии |
| `Planner/Log/` | журнал изменений по устройствам |

Формат строки задачи совместим с популярным плагином Tasks:

```
- [ ] Созвон с клиентом #работа [time:: 15:00] [dur:: 1h] [profile:: work] ⏫ 📅 2026-11-06 🆔 a2b3c
```

## Частые вопросы

**Плагин не появился на iPhone.**
Подожди, пока iCloud догрузит файлы (папка `.obsidian/plugins/weekpulse` должна быть на телефоне), и полностью перезапусти Obsidian. Проверь, что на iPhone включены сторонние плагины и что на компьютере и телефоне открыто одно и то же хранилище из iCloud.

**Я уже создал хранилище на компьютере, не в iCloud.**
Создай новое хранилище на iPhone по шагу 1, затем на Mac перенеси в его папку (iCloud Drive → Obsidian → хранилище) содержимое старого, включая скрытую папку `.obsidian`.

**Задача пропала.**
Посмотри в «Журнал изменений»: там видно, кто и когда её удалил или перенёс, и её можно вернуть. Если не помогло — «Восстановить из резервной копии…». Ещё проверь, не включён ли фильтр или другой профиль.

**Выполненные задачи не видны.**
Они скрыты: клавиша `d` или `⋯` → «Показать выполненные».

**Не вижу задачи коллеги / задачи с другого устройства.**
Планер личный: данные лежат в твоём хранилище. Синхронизация идёт только между твоими устройствами.

**Как обновить плагин.**
Замени три файла в `.obsidian/plugins/weekpulse/` новыми и перезапусти Obsidian. Задачи и настройки сохранятся.
