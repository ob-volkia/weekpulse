# Week Planner — план доработок

Идём по блокам, сверху вниз. Отмечаем `[x]`, когда пункт выложен и проверен на Mac и iPhone.

## 1. Надёжность данных — готово (2.7)
- [x] **1. Слияние при записи.** Если файл изменили на другом устройстве, правки сливаются по задачам и дням привычек, а не перетираются.
- [x] **2. Очистка вложений.** Команда находит файлы в `Attachments`, на которые не ссылается ни одна задача, и предлагает удалить их в корзину.
- [x] **3. Журнал изменений.** Что, когда и с какого устройства изменено; удалённую задачу можно вернуть из журнала.

## 2. iPhone без открытого Obsidian
- [x] **4. Виджет «Сегодня»** на экране «Домой» (Scriptable): задачи на сегодня из `Planner/Export/planner.json`.
- [x] **5. Напоминания Apple:** скрипт Scriptable по автоматизации «Команд» ведёт список «Планер» и планирует уведомления; отметка в Напоминаниях закрывает задачу.
- [ ] **6. Вместе настроить Siri и календарь** и проверить по отладке.

## 3. Работа с задачами
- [ ] **7. Клавиатура на ПК:** ↑↓ / j k — выбор, x — выполнено, Enter — открыть, 1–7 — перенос на день недели.
- [ ] **8. Перенос на другую неделю** перетаскиванием задачи на стрелку ‹ / ›.
- [ ] **9. Шкала на iPhone:** почасовой вид одного дня с перетаскиванием по времени.
- [ ] **10. Экран проектов:** проекты, их задачи, прогресс и время.
- [ ] **11. Разбор бэклога:** по одной задаче — Сегодня / На неделю / Когда-нибудь / Удалить.

## 4. Аналитика
- [ ] **12. Тренды за несколько недель:** выполнение, часы по тегам и проектам, точность оценок, продуктивные дни.

## 5. Порядок в коде
- [ ] **13. Разбить экран недели на модули** и запускать тесты автоматически перед каждой выкладкой.
